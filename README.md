# Инкапсул-Склад

Учебная модификация 1С:Предприятие для проекта "Мини-Склад".

## Описание

Конфигурация реализует базовый складской учёт:

- **Справочники:** Товары, Контрагенты
- **Документы:** Поступление, Реализация
- **Подсистема:** Мини-Склад

## Как открыть

1. Установите платформу 1С:Предприятие 8.3
2. Создайте новую базу данных
3. Загрузите конфигурацию из файлов: **Конфигурация → Загрузить конфигурацию из файлов...**
4. Укажите путь к папке с выгрузкой

## Структура репозитория

- `/Справочники/` — справочники Товары и Контрагенты
- `/Документы/` — документы Поступление и Реализация
- `/Подсистемы/` — подсистема Мини-Склад
